## Featured Projects

### 1. Orion AI Workspace

**An AI-powered workspace for productivity, document intelligence, and collaboration.** Orion AI Workspace brings multiple AI providers and collaborative workspace features together, with user-controlled API keys as a central part of its approach.

- Multi-provider AI conversations and streaming responses.
- Workspace sharing, role-based access, and real-time collaboration features.
- Document-focused AI workflows and support for multiple content formats.
- Privacy-oriented design with user control over AI provider credentials.

**Built with:** React, TypeScript, Tailwind CSS, Vite, Node.js, Python, FastAPI, and PostgreSQL-based services.

### 2. Orion AI Question Forge

**An AI-assisted platform for generating and reviewing academic assessments from learning materials.** Question Forge explores an agentic workflow in which one step generates questions and another reviews them for quality and alignment with the source material.

- RAG-based document grounding using PostgreSQL and pgvector.
- Generator-and-auditor workflow for question drafting and review.
- Configurable difficulty and alignment with Bloom's taxonomy.
- Export-oriented assessment workflows, including QTI and PDF.
- Exploration of cloud and local LLM options for different privacy needs.

**Built with:** React, Vite, Tailwind CSS, FastAPI, PostgreSQL, pgvector, Pydantic AI, LangChain, Docker, and local/cloud LLM integrations.
